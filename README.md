## Implementations

### Task 3 – Static Product Information Web Page
A semantic HTML5 product page for the fictional AeroCharge One product.

Features include:

- semantic HTML5 structure
- headings and paragraphs
- product image with alternative text
- unordered feature list
- separate product-information page
- pricing and availability table
- fictional customer reviews
- responsive CSS
- accessibility considerations

Folder:

`/task3/`

### Task 4 – Responsive Product Layout Using Bootstrap Grid

A responsive fictional product catalogue implemented with Bootstrap 5.

Required responsive classes:

`col-sm-12 col-md-6 col-lg-4`

Result:

- Small screens: 1 product per row
- Medium screens: 2 products per row
- Large screens: 3 products per row

Folder:

`/task4/`
